# Techfest — Landing Page Concept

A no-3D, editorial/futuristic landing page concept for Techfest IIT Bombay.

## Concept
"BUILD WHAT'S NEXT." — a high-energy command-center aesthetic built with:
- CSS grid / scanline atmosphere
- Typography-led hero
- Neon acid-green accent
- Animated ticker and signal bars
- Responsive event cards
- Workshops section
- Countdown
- No 3D assets or external image assets

## Run
Open `index.html` directly, or run:
`python -m http.server 5500`

Then visit `http://localhost:5500`.

## GitHub submission
Create a repository named something like `techfest-landing-page`, upload these three files, and submit the repository URL.

## Demo recording
